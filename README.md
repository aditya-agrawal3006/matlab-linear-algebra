# MATLAB Linear Algebra & Numerical Computing

A collection of MATLAB exercises and reports exploring linear systems, transformations, subspaces, eigenvalues, and matrix computations. The reports contain MATLAB commands, numerical results, and written explanations.

| Project | Focus | Files |
| --- | --- | --- |
| [Linear Algebra Foundations](projects/linear-algebra-foundations/) | Systems of equations, matrix arithmetic, subspaces, determinants, basis changes, and orthogonality | [Report](projects/linear-algebra-foundations/report.pdf) |
| [Gaussian Elimination & Linear Systems](projects/gaussian-elimination-and-linear-systems/) | Manual matrix row operations and reduced row-echelon form | [Report](projects/gaussian-elimination-and-linear-systems/report.pdf) |
| [Transformations & Matrix Inverses](projects/transformations-and-matrix-inverses/) | Rotations, reflections, matrix products, inverses, and determinants | [Report](projects/transformations-and-matrix-inverses/report.pdf) |
| [Subspaces & Linear Independence](projects/subspaces-and-linear-independence/) | Span, linear independence, invertibility, and determinants | [Report](projects/subspaces-and-linear-independence/report.pdf) |
| [Eigenvalues & Orthogonality](projects/eigenvalues-and-orthogonality/) | Change of basis, eigenvalues, diagonalization, dot products, and orthonormality | [Report](projects/eigenvalues-and-orthogonality/report.pdf) · [MATLAB source](projects/eigenvalues-and-orthogonality/analysis.m) |

## Viewing / running

The PDF reports are viewable directly on GitHub. **Only the Eigenvalues & Orthogonality project includes an editable MATLAB `.m` script**; the other projects are preserved as report PDFs. Open its source file in MATLAB and run sections independently as appropriate for the included exercises. Some commands use the Symbolic Math Toolbox.

## Project background

Prepared as coursework at the **University of Maryland**. These are student exercise reports, not novel research or a reusable software library. Assignment prompts, formats, or supporting examples may have originated from the course; original reports are retained without editing their contents.
